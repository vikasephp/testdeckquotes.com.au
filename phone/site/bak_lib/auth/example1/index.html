iCreativa User Authentication Suite:
Example 1.

Welcome to Example 1 of iCreativa User Authentication Suite. This is the simplest example of the three available. It's made using the base Auth class and only allows access to those users that have an account in the system. It also demostrates how to integrate Auth to an existing database.

Installing

Follow intructions from the INSTALL.html file. If you want to be sure that Auth Suite is supported by your PHP installation use the check.php script before installing.

Details.

This example consist of four pages and three support files:

  • conf.php stores the database connection information.
  • header.php and footer.php are just HTML templates for the site.
  • main.php is the main page for the site.
  • login.php is a login form.
  • A page with protected content.
  • A logout page.

The main page is able to update it's content if the user has already identified but loggin in is optional and the login form redirects to the main page if the user has an account. The database used in this examples is the one in the MySQL.sql file.
