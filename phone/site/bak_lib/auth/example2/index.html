iCreativa User Authentication Suite:
Example 2.

Welcome to Example 2 of iCreativa User Authentication Suite. This time we used the class GroupAuth class wich clasifies users in groups thus allowing user's access only to those zones where they have permisions.

Installing

As always this link to the install.php script and follow instructions.

Details.

This test is a little more complex that the previus one. There are two groups in the database: "admins" and "members"; although, of course, there is no limit in the number of groups you can create.

Also, in this example we used the cacheLevel property to prevent caching of the content. This increases security but you shouldn't use it in the whole site as this also increases the trafic and is kind of disturbing for the user.
